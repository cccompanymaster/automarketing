## 채널로 할 수 있는 것

2026-11-24 기준으로 정리했어요.

| 기능 | 가게 활용 |
|---|---|
| 1:1 채팅 | 예약·문의 받기 |
| 자동 응답 | 영업시간 외 안내, 자주 묻는 질문 |
| 소식 | 휴무·신메뉴 공지 |
| 메시지 발송 | 채널 친구에게 이벤트 안내 (규칙 준수) |
| 쿠폰 | 다음 방문 쿠폰 |

## 개설하고 꾸미기

1. 카카오톡 채널 관리자센터에서 채널을 만들어요.
2. 프로필 사진(로고나 대표 사진), 가게 이름, 소개 한 줄을 넣어요.
3. 영업시간·주소·전화·예약 링크를 채워요. 네이버 플레이스와 똑같이 맞추세요.
4. 자동 응답에 자주 묻는 질문 답을 넣어요 ([가게 문의 응대 매뉴얼](/column/inquiry-response-guide/)).

## 친구 모으기 (정직한 방법)

| 방법 | 예시 |
|---|---|
| 매장 안내 | 테이블·계산대에 QR 코드 |
| 영수증·포장 | "채널 추가하면 다음 방문 음료 1잔" |
| 다른 채널 연결 | 인스타그램 프로필·플레이스에 채널 링크 |

친구 수를 사서 늘리지 마세요. 실제 손님이 아닌 친구는 메시지 비용만 늘리고 반응은 없어요.

## 광고 메시지 규칙

| 규칙 | 내용 |
|---|---|
| (광고) 표시 | 메시지 첫머리 |
| 보낸 곳 | 가게 이름·연락처 |
| 수신거부 | 쉽게 거부할 수 있는 방법 |
| 야간 | 밤 9시~아침 8시는 별도 동의 없이 보내지 않기 |

자세한 규칙은 [광고 문자 보내는 법](/column/ad-sms-rules/)과 같아요.

## 채널별 역할 나누기

| 채널 | 역할 |
|---|---|
| 카카오톡 채널 | 문의·예약, 단골 소식 |
| 문자 | 동의한 손님에게 중요 이벤트 |
| 인스타그램 DM | 새 손님 문의 |

단골 관리 방법은 [단골 만드는 법](/column/loyalty-program-guide/)을 참고하세요. 다른 운영 가이드는 [마케팅 칼럼](/column/)에 모아 두었어요.
