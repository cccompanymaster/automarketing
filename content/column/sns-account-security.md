## 지금 바로 할 5가지

2026-11-21 기준으로 정리했어요.

| 수칙 | 하는 법 |
|---|---|
| 2단계 인증 켜기 | 각 플랫폼 보안 설정에서 문자·인증 앱 인증 사용 |
| 채널마다 다른 비밀번호 | 한 곳이 털려도 다른 곳까지 번지지 않게 |
| 복구 연락처 점검 | 계정에 등록된 휴대폰·이메일이 지금 쓰는 것인지 확인 |
| 로그인 기록 확인 | 모르는 기기·지역 로그인이 있으면 바로 비밀번호 변경 |
| 관리자 권한 정리 | 그만둔 직원·끝난 대행사 권한 삭제 |

## 사칭 메시지 구별하기

| 의심할 신호 | 대응 |
|---|---|
| "24시간 안에 확인하지 않으면 계정 정지" | 링크 누르지 말고 앱에서 직접 확인 |
| 비밀번호·인증번호를 묻는 DM·문자 | 공식 고객센터는 묻지 않아요 |
| "상위노출 보장, 계정만 주세요" | 계정 탈취·어뷰징 위험, 응하지 않기 |

이미 클릭했거나 비밀번호를 입력했다면 바로 비밀번호를 바꾸고, 한국인터넷진흥원 보호나라(국번 없이 118)에 상담하세요.

## 대행에 계정을 맡길 때

1. **비밀번호가 정말 필요한지 먼저 묻기**: 글 배포·리워드·리뷰 답글 대행 등은 대부분 계정 없이 진행돼요.
2. **꼭 줘야 한다면 임시 비밀번호로**: 작업 전에 바꾸고, 끝나면 **즉시 다시 바꾸기**.
3. **2단계 인증 대응 방법을 정하기**: 인증번호를 메신저로 요구하는 방식은 피하세요.
4. **작업 범위와 기간을 문서로**: 무엇을, 언제까지 하는지 정해 두기 ([마케팅 대행 맡길 때 준비할 자료](/column/marketing-order-checklist/)).

## 마케팅방주는 이렇게 처리해요

- 인스타그램·유튜브 상품은 **로그인 정보를 받지 않아요**.
- 블로그 이웃 추가처럼 계정 로그인이 꼭 필요한 상품만 비밀번호를 받아요.
- 받은 비밀번호는 주문 내용과 따로 보관해 관리자만 볼 수 있고, **작업이 끝나거나 취소되면 바로 지워져요**.
- 작업이 끝나면 비밀번호를 꼭 바꿔 주세요.
