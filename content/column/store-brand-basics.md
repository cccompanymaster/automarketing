## 1단계 — 가게를 한 문장으로

2026-11-23 기준으로 정리했어요.

**"[누구에게] [무엇을] [어떻게] 하는 가게"**

| 예시 |
|---|
| 연수동 직장인에게 15분 안에 나오는 집밥 정식을 파는 가게 |
| 동네 아이 엄마들이 편하게 머무는 노키즈존 아닌 카페 |
| 매일 아침 직접 반죽하는 크루아상 전문 베이커리 |

이 문장이 소개글, 블로그, 인터뷰 글의 출발점이 돼요 ([사장님 인터뷰 글 만드는 법](/column/owner-interview-content/)).

## 2단계 — 색·글꼴 정하기

| 항목 | 기준 |
|---|---|
| 대표 색 | 1~2개 (인테리어·간판에서 가장 많이 보이는 색) |
| 보조 색 | 흰색·검정 등 읽기 쉬운 색 |
| 글꼴 | 제목용 1개, 본문용 1개 (무료 상업 이용 가능한 글꼴) |

## 3단계 — 말투 정하기

| 항목 | 예시 |
|---|---|
| 손님 부르는 말 | "손님" / "여러분" 중 하나로 |
| 문장 끝 | "~해요" 체로 통일 |
| 자주 쓰는 표현 | "오늘도 갓 구웠어요" 같은 가게만의 한마디 |
| 쓰지 않는 표현 | 과장("최고", "1등"), 다른 가게 비교 |

## 통일 체크리스트

| 채널 | 확인할 것 |
|---|---|
| 간판·메뉴판 | 가게 이름 표기, 색 |
| 네이버 플레이스·카카오맵 | 소개 문장, 대표 사진 톤 |
| 인스타그램 | 프로필 이름·소개·하이라이트 커버 ([가게 인스타그램 프로필 꾸미기](/column/instagram-profile-setup/)) |
| 블로그 | 글머리 인사말, 말투 |
| 포장재·영수증 | 이름·색 |

## 이름은 먼저 확인하세요

간판·포장재에 이름을 새기기 전에 같은 업종에서 이미 상표로 등록된 이름인지 확인하세요 ([가게 이름 상표 등록, 해야 할까](/column/store-name-trademark/)).

로고·가격표 같은 이미지 제작은 마케팅방주 당근 상품의 **업체로고 이미지**(별도 문의)로 상담할 수 있어요. 다른 운영 가이드는 [마케팅 칼럼](/column/)에 모아 두었어요.
