## 한눈에 보기

상가건물 임대차보호법 기준이에요 (2026-11-16 확인).

| 항목 | 내용 |
|---|---|
| 갱신 요구 가능 기간 | 최초 계약 포함 **전체 10년** 이내 |
| 요구하는 시기 | 계약 만료 **6개월 전부터 1개월 전까지** |
| 갱신되는 조건 | 전 계약과 같은 조건 (차임은 증감 가능) |
| 월세 증액 상한 | 5% 이내, 증액 후 1년 안 재증액 불가 (환산보증금 기준 이하) |
| 권리금 회수 보호 | 계약 만료 6개월 전부터 만료 때까지 |

## 집주인이 거절할 수 있는 경우

아래 사유가 있으면 갱신 요구를 거절할 수 있어요 (같은 법 제10조).

| 사유 | 예시 |
|---|---|
| 차임 연체 | 3기의 차임액에 해당하는 금액에 이를 만큼 연체한 사실이 있음 |
| 거짓·부정한 방법으로 임차 | — |
| 서로 합의해 상당한 보상을 제공 | — |
| 동의 없는 전대 | 집주인 동의 없이 다른 사람에게 다시 빌려줌 |
| 고의·중대한 과실로 파손 | 건물 일부를 크게 부숨 |
| 건물 멸실, 철거·재건축 | 계약 때 계획을 미리 알린 경우 등 법정 요건 충족 |
| 그 밖에 임차인 의무를 현저히 위반 | — |

월세를 여러 번 밀리면 갱신을 거절당할 수 있으니, 자금이 빠듯할 때는 [손익분기점](/blog/breakeven-point-calculation/)부터 다시 점검하세요.

## 아무 말이 없으면 — 묵시적 갱신

집주인이 만료 6개월~1개월 전까지 갱신 거절이나 조건 변경을 알리지 않으면 **전과 같은 조건으로 1년** 다시 계약한 것으로 봐요. 이때 임차인은 언제든 해지를 통보할 수 있고, 통보 후 3개월이 지나면 해지돼요. (환산보증금 기준 이하 임대차에 적용)

## 꼭 챙길 것

1. **만료일 6개월 전을 달력에 표시**: 요구 기간을 놓치지 않게요.
2. **요구는 기록이 남게**: 문자·내용증명으로 날짜와 내용을 남겨요.
3. **임대료 부담 점검**: 갱신 전에 매출 대비 임대료가 적정한지 [적정 임대료 비율](/blog/rent-to-sales-ratio/)로 확인하세요.
4. **그만둘 계획이라면**: 권리금 회수 보호 기간(만료 6개월 전~만료)에 새 임차인을 주선하고, 폐업 절차는 [폐업 신고 방법](/blog/business-closure-report/)을 참고하세요.
