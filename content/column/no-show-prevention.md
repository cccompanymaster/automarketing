## 1단계 — 예약받을 때 알릴 것

2026-11-26 기준으로 정리했어요.

| 알릴 것 | 예시 |
|---|---|
| 예약 확정 내용 | 날짜·시간·인원 |
| 늦을 때 기준 | "15분 지나면 자리가 취소될 수 있어요" |
| 취소·변경 마감 | "방문 전날 오후 6시까지 연락 주세요" |
| 예약금 여부 | 단체·인기 시간대만 |

이 내용을 예약 문자나 채팅으로 남기고 손님 확인을 받아 두세요. 예약 연락처는 예약 확인에만 써요.

## 2단계 — 확인 연락

```
[○○식당] 내일(토) 18:30, 4명 예약 확인드려요.
변경·취소는 오늘 18시까지 이 번호로 답장 주세요.
오시는 길: (지도 링크)
```

| 시점 | 내용 |
|---|---|
| 전날 | 예약 확인 + 취소 마감 안내 |
| 당일 2~3시간 전 | 짧은 확인 (단체 예약) |

카카오톡 채널로 예약을 받는다면 채널 메시지로 보내도 돼요 ([카카오톡 채널 활용법](/column/kakao-channel-guide/)).

## 3단계 — 예약금과 취소 규정

- **대상**: 단체, 코스, 주말 저녁처럼 노쇼 손실이 큰 예약만
- **환불 기준**: 몇 시간 전까지 취소하면 전액 환불인지 분명히
- **안내 방법**: 예약금 받기 전에 규정을 보여 주고 동의 받기

금액과 환불 기준은 공정거래위원회 소비자분쟁해결기준을 참고해 무리하지 않게 정하세요. 연말 단체 예약 조건은 [연말 마케팅 준비](/column/year-end-marketing-plan/)에도 정리했어요.

## 빈자리 채우기

| 방법 | 내용 |
|---|---|
| 대기 명단 | 취소가 생기면 대기 손님에게 순서대로 연락 |
| 당일 소식 | "오늘 19시 2자리 비어요" 플레이스·스토리 공지 |

## 하지 말아야 할 것

- 예약금 규정을 알리지 않고 나중에 위약금 요구하기
