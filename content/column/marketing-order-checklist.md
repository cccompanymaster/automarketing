## 공통으로 준비할 4가지

어떤 상품이든 아래 네 가지가 있으면 작업이 빨리 시작돼요 (2026-11-07 기준 주문서 항목).

| 자료 | 예시 |
|---|---|
| 주소(URL) | 네이버 플레이스, 블로그, 당근 비즈프로필, 상품 페이지 주소 |
| 희망 키워드 | "송도 맛집, 송도 삼겹살"처럼 쉼표로 여러 개 |
| 업체 정보 | 업체명, 위치, 영업시간, 대표 상품 2~3개, 강점, 주요 고객층 |
| 원고·사진 | 직접 쓴 원고, 직접 찍은 매장·메뉴 사진 |

## 상품별 준비 자료

| 상품 | 주문서에 넣을 것 | 참고 |
|---|---|---|
| 블로그 배포 (실명·준최적·최적) | 희망 키워드, 원고·사진 파일 | 원고가 없으면 블로그용 원고 작성 1건 500원 |
| 공식 인플루언서 블로그 배포 | 희망 키워드, 원고·사진 파일, 카테고리 지정 여부 | 카테고리 지정 시 1건 +20,000원 |
| 블로그용 원고 작성 | 업체명, 대표 상품, 강점, 포스팅 방향, 사진 유무 | 빈칸 양식대로 채우면 돼요 |
| 플레이스 메타데이터 SEO 세팅 | 플레이스 URL, 희망 키워드, 업체 정보 | 1회 50,000원 |
| 카페 배포형·노출용 게시글 | 희망 카페(카테고리), 원고 | 원고는 요청사항 칸에 3,000자까지 |
| AI 검색 최적화(AEO) | 업체명, 위치, 영업시간, 링크, 대표 상품, 강점 | 기본 세팅 1회 150,000원 |
| 보도자료 송출 | 희망 언론사, 원고(직접·대필), 이미지 요청사항 | 원고 대필 1건 10,000원 |
| 당근 상품 | 비즈프로필 주소, 광고계정 유무, 소식글 주소, 알리고 싶은 내용 | 계정이 없으면 세팅 상품부터 |

가격은 모두 부가세 별도예요.

## 파일 올릴 때

- 사진: 직접 찍은 원본 사진이 좋아요. 다른 블로그 사진은 저작권 문제가 생길 수 있어요.
- 문서: 한글·워드·PDF·텍스트 모두 돼요.
- 한도: 파일당 20MB, 주문당 최대 20개예요. 사진이 많으면 압축 파일 하나로 올려도 돼요.

## 이런 정보는 넣지 마세요

- 블로그 이웃 관련 상품 외에는 **비밀번호가 필요 없어요.** 주소만으로 진행해요.
- 주민등록번호, 카드번호 같은 정보는 어떤 주문에도 필요하지 않아요.
