## 찍기 전에 정할 것

2026-11-16 기준으로 정리했어요.

| 항목 | 기본값 |
|---|---|
| 방향 | **세로** (휴대폰을 세워서) |
| 길이 | 15~30초로 시작 |
| 빛 | 창가 자연광, 역광 피하기 |
| 소리 | 자막만으로도 이해되게 (소리 끄고 보는 사람이 많아요) |

## 첫 장면에 결과부터

숏폼은 첫 1~2초에 계속 볼지가 정해져요. 과정부터 보여 주기보다 **완성된 결과를 먼저** 보여 주고 과정을 이어 붙이세요.

| 순서 | 장면 | 예시 (빵집) |
|---|---|---|
| 1 | 결과 | 갓 나온 크루아상 단면 |
| 2 | 과정 | 반죽 접기 → 오븐 |
| 3 | 정보 | 가격·판매 시간 자막 |
| 4 | 행동 | "오후 3시 두 번째 굽기" + 위치 |

## 업종별 장면 아이디어

| 업종 | 장면 |
|---|---|
| 음식점·카페 | 플레이팅, 지글지글 굽는 소리, 포장 과정 |
| 미용실·네일 | 시술 전후 (손님 동의), 도구 정리 |
| 학원·공방 | 수업 준비, 완성 작품 |
| 소매점 | 신상품 입고, 포장 과정 |

사진 촬영 요령은 [블로그 사진 찍는 법](/column/blog-photo-guide/)과 같아요. 한 번 찍은 영상을 어느 날 올릴지는 [콘텐츠 캘린더](/column/content-calendar-guide/)로 정리하세요.

## 올리기 전 확인할 것

- **음악 저작권**: 앱이 제공하는 음악이나 이용 허락된 음원만 쓰기
- **손님 얼굴**: 알아볼 수 있으면 동의 받기
- **과장 표현**: "지역 1등", "무조건" 같은 근거 없는 표현 빼기
- **대가성**: 협찬받은 제품이 나오면 광고 표시 ([협찬·광고 표시 하는 법](/column/sponsored-post-disclosure/))
