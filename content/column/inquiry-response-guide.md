## 먼저 자주 묻는 질문 10개를 정리해요

최근 한 달 동안 받은 문의를 모아 보면 대부분 비슷해요 (2026-11-20 기준 정리).

| 질문 | 미리 정해 둘 답 |
|---|---|
| 영업시간·휴무일 | 요일별 시간, 이번 달 휴무 |
| 주차 | 가능 여부, 위치, 무료 시간 |
| 예약 | 방법(전화·네이버 예약 등), 단체 기준 |
| 가격 | 대표 메뉴·서비스 가격 |
| 포장·배달 | 가능 여부, 주문 방법 |
| 아이·반려동물 동반 | 가능 여부, 준비된 것 |
| 알레르기·재료 | 주요 재료 |
| 결제 | 카드·간편결제·현금영수증 |
| 대기 | 붐비는 시간, 대기 방법 |
| 찾아오는 길 | 랜드마크 기준 설명 |

이 답을 플레이스 소개·홈페이지 FAQ에도 같이 올리면 문의 자체가 줄어요 ([가게 홈페이지, 꼭 필요할까](/column/store-website-needed/)).

## 답변 템플릿

```
[가격 문의]
안녕하세요, ○○입니다! 커트는 25,000원, 염색은 길이에 따라 60,000원부터예요.
원하시는 날짜 알려 주시면 가능한 시간 바로 안내드릴게요 :)

[예약 문의]
토요일 2시는 4명까지 가능해요. 성함과 연락처 남겨 주시면 예약 잡아 드릴게요.
(예약 확인 연락에만 사용해요)

[바빠서 바로 못 볼 때 - 자동 응답]
문의 감사합니다! 영업 중이라 확인이 늦을 수 있어요. 오후 3시 전에 꼭 답드릴게요.
```

## 응답 기준을 정해 두세요

| 채널 | 첫 답 목표 |
|---|---|
| 전화 | 바로 (못 받으면 문자로 "확인 후 연락드릴게요") |
| 카카오톡·DM | 영업시간 중 30분 안 |
| 영업시간 외 | 자동 응답 + 다음 날 오픈 직후 |

## 주의할 점

- **개인정보**: 예약에 필요한 이름·연락처만 받고, 그 목적에만 써요. 홍보 연락은 별도 동의가 필요해요 ([광고 문자 보내는 법](/column/ad-sms-rules/)).
- **불만 문의**: 사과 → 사실 확인 → 해결 방법 순서로 답하고, 감정적으로 반박하지 않아요. 리뷰에 남은 불만은 [리뷰 답글 쓰는 법](/column/review-reply-guide/)을 참고하세요.
- **다음 행동 안내**: 모든 답 끝에 "예약은 여기서", "날짜 알려 주세요"처럼 다음 단계를 붙여요.

다른 운영 가이드는 [마케팅 칼럼](/column/)에 모아 두었어요.
