## 언제 표시해야 하나

가게가 블로거·인플루언서·손님에게 **대가를 주고** 후기나 추천 글을 쓰게 했다면 그 사실을 밝혀야 해요. 공정거래위원회 「추천·보증 등에 관한 표시·광고 심사지침」 기준이에요 (2026-11-11 확인).

| 대가의 종류 | 표시 대상인가 |
|---|---|
| 원고료·현금 | 표시 |
| 음식·제품 무료 제공 | 표시 |
| 할인·쿠폰·포인트 | 표시 |
| 판매 수수료(제휴 링크) | 표시 |
| 대가 없이 손님이 스스로 쓴 후기 | 표시 대상 아님 |

## 어디에, 어떻게 표시하나

| 채널 | 표시 위치 |
|---|---|
| 블로그·카페 글 | 제목 또는 본문 첫 부분 |
| 인스타그램 등 사진 게시물 | 사진 안이나 본문 첫 부분 (더보기 전에 보이게) |
| 유튜브 등 영상 | 제목이나 영상 시작 부분과 끝 부분 |
| 실시간 방송 | 방송 중 일정 간격으로 반복 |

- **문구**: "광고", "협찬", "○○로부터 제품을 무상으로 받아 작성했어요"처럼 누구나 알아볼 수 있는 한글로 써요.
- **크기·색**: 본문과 구별되게, 배경색에 묻히지 않게 써요.
- **피할 표현**: "Thanks to", "#ad"처럼 뜻이 모호하거나 외국어만 쓴 표시, 해시태그 사이에 섞어 둔 표시, 댓글이나 '더보기' 안에 숨긴 표시는 제대로 표시한 것으로 보기 어려워요.

## 표시하지 않으면

대가를 숨긴 추천 글은 표시·광고법상 **기만적인 광고**가 될 수 있어요. 이 경우 광고를 의뢰한 사업자가 시정명령을 받거나, 관련 매출액의 2% 이내(매출액을 정하기 어려우면 5억 원 이내)에서 과징금을 받을 수 있어요. 후기를 써 준 사람이 표시를 빠뜨려도 의뢰한 가게가 책임을 피하기 어려우니, 의뢰할 때 표시 문구와 위치를 조건으로 정해 두세요.

## 의뢰할 때 체크리스트

1. 대가(원고료·무료 제공·할인)를 주는지 먼저 정리하기
2. 표시 문구와 위치(제목 또는 첫 부분)를 의뢰서에 적기
3. 발행 후 링크를 받아 표시가 실제로 들어갔는지 확인하기
4. 가짜 손님 행세, 실제로 쓰지 않은 제품 후기는 의뢰하지 않기
