## 상호와 상표는 달라요

상표법과 특허청 안내 기준이에요 (2026-11-19 확인).

| 구분 | 상호 | 상표 |
|---|---|---|
| 어디에 | 사업자등록증 | 특허청 상표 등록 |
| 역할 | 세금·거래에서 사업자를 구분 | 상품·서비스의 출처를 표시하는 **독점 권리** |
| 같은 이름을 남이 쓰면 | 막기 어려움 | 같은·비슷한 업종에서 사용 금지 요구 가능 |
| 기간 | 사업 기간 | 등록일부터 10년, 갱신 가능 |

상표는 **먼저 출원한 사람**이 우선이에요. 먼저 가게를 열었더라도 다른 사람이 먼저 출원해 등록하면 분쟁이 생길 수 있어요.

## 이럴 때는 출원을 고려하세요

- 간판·포장·SNS 계정 이름까지 같은 이름으로 오래 쓸 계획
- 지점을 내거나 프랜차이즈를 생각 중
- 온라인 판매·밀키트 등으로 지역 밖까지 팔 계획
- 리브랜딩 비용이 큰 업종 (인테리어·간판에 이름이 많이 들어감)

## 출원 전에 이름 찾아보기

1. **키프리스**(kipris.or.kr)에서 가게 이름을 검색해요.
2. 같은 이름뿐 아니라 **발음·뜻이 비슷한 이름**도 확인해요.
3. 우리 업종과 같은 **상품 분류**에 이미 있는지 봐요.

| 업종 | 주로 해당하는 분류 |
|---|---|
| 음식점·카페 | 43류 (음식·음료 제공업) |
| 미용실·네일·피부관리 | 44류 |
| 학원·교습 | 41류 |
| 온라인 쇼핑몰·도소매 | 35류 |
| 직접 만든 식품 판매 | 식품 종류별 상품 분류 (예: 30류 빵·과자) |

## 출원 순서

1. 이름과 로고(있다면) 확정
2. 업종에 맞는 분류와 지정상품 고르기
3. 특허청에 출원 (직접 또는 변리사)
4. 심사 → 등록 결정 → 등록료 납부

비용과 심사 기간은 분류 수와 출원 방식에 따라 달라져요. 특허청 안내에서 최신 수수료를 확인하세요.

## 이름을 정했다면

이름을 확정했다면 가게 소개·홈페이지·SNS에 같은 이름을 쓰세요. 이름과 정보를 맞추는 법은 [가게 홈페이지, 꼭 필요할까](/column/store-website-needed/)를, 오픈 일정은 [가게 오픈 전 마케팅 준비](/column/store-opening-marketing-checklist/)를 참고하세요. 이름에 담은 이야기는 [사장님 인터뷰 글](/column/owner-interview-content/)로 풀어 쓰면 좋아요. 다른 운영 가이드는 [마케팅 칼럼](/column/)에 모아 두었어요.
