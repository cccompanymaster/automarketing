## 잘 맞는 제휴 상대

2026-11-26 기준으로 정리했어요.

| 우리 가게 | 잘 맞는 이웃 가게 |
|---|---|
| 카페 | 꽃집, 서점, 네일샵 |
| 필라테스·요가 | 샐러드·건강식, 스포츠웨어 |
| 미용실 | 네일샵, 사진관 |
| 학원 | 문구점, 분식점 |
| 고깃집 | 2차로 가는 카페·디저트 가게 |

**기준**: 손님층(나이·동네·생활 패턴)은 겹치고, 파는 것은 다른 가게.

## 제휴 방식 3가지

| 방식 | 예시 | 부담 |
|---|---|---|
| 쿠폰 교환 | "옆 꽃집 영수증 보여 주면 음료 1,000원 할인" | 낮음 |
| 공동 이벤트 | 거리 스탬프 투어, 기념일 공동 행사 | 중간 |
| 세트 상품 | "필라테스 체험 + 샐러드" 묶음 | 정산 필요 |

## 약속은 글로 정해요

- 할인·혜택 내용과 기간
- 쿠폰·안내물을 어디에 얼마나 둘지
- 비용 부담과 정산 방법
- 끝내는 조건 (예: 한쪽이 원하면 2주 전 알림)

## 효과 세기

| 항목 | 방법 |
|---|---|
| 쿠폰 사용 수 | 제휴처별로 다른 쿠폰 문구·색 |
| 새 손님 비율 | "어떻게 알고 오셨어요?" 한마디 |
| 온라인 유입 | 제휴처 안내물 QR에 [UTM](/column/utm-link-guide/) 붙이기 |

할인 폭은 [할인 이벤트 기획하는 법](/column/store-promotion-planning/)으로 먼저 계산하고, 제휴로 온 손님을 다시 오게 하려면 [단골 만드는 법](/column/loyalty-program-guide/)을 함께 보세요.

## 주의할 점

- 서로 대가를 주고받는 SNS 소개 글에는 '제휴' 표시 ([협찬·광고 표시 하는 법](/column/sponsored-post-disclosure/))
- 상대 가게 사진·로고는 허락을 받고 사용
- 손님 정보는 서로 넘기지 않기
