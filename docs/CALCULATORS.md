# 자영업자 무료 계산기 (26종)

허브: `/tools/` · 배달 수익 계산기만 `/delivery/`, 나머지는 `/tools/<slug>/`.
목록·경로·설명의 단일 출처는 `src/lib/calc/registry.ts`입니다.

## 실행 방법

```bash
npm install
npm run dev        # http://localhost:3000/tools/
npm test           # vitest — 계산 함수 단위 테스트 (src/lib/calc/__tests__)
npm run build      # 정적 export (out/)
```

## 계산기별 계산 순서·반올림

모든 금액은 계산 중 반올림하지 않고, 아래에 적은 지점에서만 원 단위로 처리합니다. 표시는 `formatWon`(원 단위 반올림).

### 배달·가격
- **배달 수익** (`delivery.ts`): 공용 함수 `orderProfit(플랫폼, 입력)` 하나로 계산.
  정산 기준 매출 = 판매가 − 업주 부담 할인(+ 가게배달만 고객 배달팁) → 중개수수료 = 기준 × 요율 (쿠팡이츠는 할인 전 판매가 기준) →
  결제수수료 = 고객 결제액 × 요율 → 수수료 부가세 = (중개+결제+업주 배달비) × 10% → 통장 입금액 → 이익 = 입금액 − 원가 − 포장비 − 월 광고비÷월 주문 − (가게배달) 대행료.
  수익률 = 이익 ÷ 할인 전 판매가. 플랫폼 차이는 독립 규칙 함수(할인 전 판매가 수수료, 가게배달 배달팁·대행료, 구간 대표 배달비, 쿠팡 포장 무료 특례).
  "실제 플랫폼 배달비"는 정산서의 **업주 부담 배달비**로 해석(고객 배달팁을 빼지 않음 — 구간제 요금에서 업주 부담은 고객 부담과 무관).
- **배달가격 역산** (`deliveryPrice.ts`): 같은 `orderProfit`로 이익 = a·가격 + b를 구해 최소가 = ⌈(목표−b)÷a⌉원 → 올림 단위(100/500/1,000원)로 올림 → 그 가격으로 `orderProfit` 재계산. 두 계산기 결과 일치를 540개 조합 테스트로 확인. 대행료 없는 가게배달은 비교에서 제외 + 경고.
- **쿠폰·리뷰이벤트** (`promotion.ts`): 쿠폰 부담 = 쿠폰액 × 업주 부담률 × 사용률, 리뷰 부담 = 원가 × 참여율 → 본전 주문 수 = ⌈(기존 월 이익 + 월 고정 이벤트비) ÷ 이벤트 후 주문당 이익⌉. 이벤트 후 이익 ≤ 0 또는 기존 이익 ≤ 0 → 본전 불가.
- **마진** (`margin.ts`): 필요 판매가 = 원가 ÷ (1 − 목표 마진율), 원 단위 **올림**. 마진율 100% 이상 → 불가능.
- **할인** (`discount.ts`): 할인가 원 단위 반올림 → 같은 이익 판매량 = ⌈기존 판매량 × 할인 전 개당 이익 ÷ 할인 후 개당 이익⌉ (기존 판매량 기본 100).
- **가격 인상** (`priceIncrease.ts`): 개당 이익 = 가격 × (1 − 수수료율) − 원가 − 주문당 비용 → 동일 이익 판매량 = ⌈(현재 월 이익 + 추가 고정비) ÷ 인상 후 개당 이익⌉ → 허용 감소율. 음수면 "더 팔아야 함" 별도 표시.
- **단가** (`unitPrice.ts`): kg→g, L→ml 환산(개·장·롤·팩·박스·직접 입력은 같은 단위끼리만). 상세: 현금 지출 = 금액×수량 − 할인 (+부가세 별도분) + 배송비 → 사용 가능 수량 = 수량 × (1 − 폐기율) → 실질 단가 = (현금 − 공제 매입세액) ÷ 사용 가능 수량. 반올림 없음(소수 2자리 표시).

### 인건비·노무
- **4대보험 공용 모듈** (`socialInsurance.ts`): 연금 = (보수 1,000원 미만 절사 → 상·하한) × 4.75%, 건강 = 보수 × 3.595%, 장기요양 = (절사된 건강보험료) × 13.14%, 고용 = 0.9% (+ 사업주 고용안정·직능), 산재 = 업종 + 출퇴근 (사업주). 모든 보험료 **개인별 10원 미만 절사**.
- **시급·주휴수당** (`hourlyWage.ts`): 주휴시간 = min(주 소정근로시간, 40) ÷ 40 × 8 (15시간 미만 0) → 일급·주급·주휴수당 원 단위 반올림 → 월 환산 = 주급 합계 × 365/7/12, 반올림.
- **4대보험 공제** (`payroll.ts`): 과세 대상 = 월급 − 비과세 → 공용 모듈 → 공제 후 = 월급 − 근로자 합계 (소득세·지방소득세 **제외**) → 총 고용비용 = 월급 + 사업주 합계.
- **인건비 비율** (`laborRatio.ts`): 사업주 부담 = 급여 합계 × 사업주 요율 합(연금 상한 무시 근사), 반올림 → 비율 = 총 인건비 ÷ 매출.
- **원천세** (`withholding.ts`): 3.3%: 소득세 = 지급액 × 3% → 10원 미만 절사, 지방세 = 소득세 × 10% → 10원 미만 절사 (소액부징수 없음). 일용: 1일 소득세 = max(0, 일당 − 15만) × 6% × 45% → 10원 미만 절사, 1,000원 미만이면 0 → × 근무일수.
- **급여명세서·근로계약서**: 아래 "문서 만들기" 참고.

### 매출·손익·세금
- **손익분기점** (`breakeven.ts`): 매출 = 고정비 ÷ (1 − 변동비율) 원 단위 올림, 주문 수 = ⌈정확한 매출 ÷ 객단가⌉, 일평균 = ÷ 영업일수(기본 30). 변동비율 100% 이상 → 불가능.
- **매출 목표** (`salesTarget.ts`): (고정비 + 목표 이익) ÷ 공헌이익률, 올림. 주문 수 올림.
- **월 고정비** (`fixedCost.ts`): 현금 유출 = 전 항목, 손익 기준 = 현금 유출 − 대출 원금. 반올림 없음.
- **재고 회전율** (`inventoryTurnover.ts`): 평균 재고 = (기초+기말)÷2, 회전율 = 매출원가 ÷ 평균 재고, 회전일수 = 기간일수(30/91/365) ÷ 회전율.
- **카드 수수료** (`cardFee.ts`): 카드별 수수료 = 매출 × 요율, 원 단위 반올림 → 실입금 = 매출 − 수수료. 카드수수료는 부가세 면세.
- **부가세** (`vat.ts`): 총액→공급가액 = 총액 ÷ 1.1 반올림, 부가세 = 총액 − 공급가액. 공급가액→부가세 = × 10% 원 미만 절사.

### 임대·창업·자금
- **임대료 비율** (`rentRatio.ts`): (임대료+관리비) ÷ 매출. 구간 경계는 아래 구간에 포함.
- **평당 임대료** (`rentPerPyeong.ts`): 1평 = 3.3058㎡로 환산, 반올림은 표시만.
- **적정 임대료** (`affordableRent.ts`): 매출 × 목표 비율, 원 단위 **절사**(목표 초과 방지).
- **창업비용** (`startupCost.ts`): 예비비 = 소모성 비용(인테리어~기타) × 예비비율, 올림 — 보증금·권리금에는 적용 안 함. 권리금은 "회수 불확실"로 별도.
- **창업 생존기간** (`startupRunway.ts`): 가용 현금 = 보유 − 비상금 − 아직 안 쓴 창업비 (−보증금, 아직 안 냈을 때) → 월 순현금 감소 = 적자 + 생활비 + 원금 − 다른 수입 → 개월 = 가용 ÷ 감소 (소수 1자리 절사). 감소 ≤ 0 → "현금이 줄지 않음".
- **대출 이자** (`loan.ts`): 월 이자 = 잔액 × 연이율 ÷ 12, 원 미만 절사. 원리금균등 월 상환액 원 단위 반올림(0%는 원금÷n), 원금균등 원금 = ⌊원금÷n⌋. 마지막 달이 잔액 전부 상환 → 원금 합계 = 대출 원금 (최대 600개월 테스트).
- **폐업비용** (`closingCost.ts`): 회수 합계 − 지출 합계 = 남는 돈 / 부족액. 반올림 없음.

  스팸 방지: 숨은 필드(honeypot) + 페이지 체류 3초 + IP 해시 기준 10분 5회(삭제 10회) 제한 + 1시간 내 중복 금지 + 링크 2개 제한. IP 해시는 별도 테이블에 1일 보관.
  출력은 React 텍스트 노드로만 렌더(자동 이스케이프). 스키마: `supabase/schema.sql` 하단.

## 참고 사이트와 다르게 적용한 가정

참고 사이트(calc.assasup.com)는 이 환경에서 접속이 차단돼 화면을 직접 비교하지 못했습니다. 요청 명세를 기준으로 구현했고, 명세에 없던 판단은 다음과 같습니다.
- 배달: "실제 플랫폼 배달비"를 업주 부담 배달비로 해석, 수익률 분모를 할인 전 판매가로 통일, 구간 대표 배달비는 공개 구간의 중간값, 요기요의 주문 수 기준 구간을 매출 구간 선택에 대응.
- 쿠폰 사용률·부담률을 비워 두면 100%(보수적)로 계산.
- 세액·보험료 절사 단위(10원)를 실무 기준으로 적용.
- 인건비 비율의 사업주 4대보험은 급여 합계에 요율을 곱한 근사치(연금 상한 무시).
- 부담 진단 구간(인건비·임대료)은 일반적인 참고 기준으로 가정값 표시.
