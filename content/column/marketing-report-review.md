## 세 가지로 검수해요

2026-11-20 기준으로 정리했어요.

| 기준 | 확인할 것 |
|---|---|
| **링크** | 받은 링크가 실제로 열리는지, 우리 가게 이야기가 맞는지 |
| **캡처** | 세팅 전후 화면, 발행 날짜, 주문한 수량이 보이는지 |
| **숫자** | 작업 뒤 문의·예약·방문·유입이 어떻게 바뀌었는지 |

## 상품별 확인 항목

| 상품 종류 | 확인할 것 |
|---|---|
| 블로그·카페 글 | 링크, 발행일, 가게 이름·주소·사진이 정확한지, 광고 표시 |
| 보도자료 | 실린 매체 목록과 기사 링크 |
| 플레이스 정보 세팅 | 바뀐 항목의 전후 캡처 |
| 원고 작성 | 사실(가격·영업시간)이 맞는지, 과장 표현이 없는지 |

대가를 주고 쓴 글에는 광고 표시가 들어가야 해요. 위치와 문구는 [협찬·광고 표시 하는 법](/column/sponsored-post-disclosure/)에서 확인하세요.

## 숫자는 이렇게 비교해요

- 작업 **전 2~4주**와 **후 2~4주**를 같은 요일 수로 비교해요.
- 문의·예약 수를 가장 먼저 보고, 노출·클릭은 원인을 찾을 때 봐요 ([마케팅 성과 지표 뜻](/column/marketing-metrics-glossary/)).
- 링크에 [UTM](/column/utm-link-guide/)을 붙여 두면 어느 글에서 들어왔는지 나눠 볼 수 있어요.
- 블로그 검색 노출은 [블로그 글 노출 확인 방법](/column/blog-exposure-check/)으로 직접 확인해요.

## 수정 요청은 구체적으로

| 좋은 요청 | 아쉬운 요청 |
|---|---|
| "3번째 사진의 가격 표기를 12,000원으로 바꿔 주세요" | "좀 별로예요" |
| "영업시간을 11시~21시로 고쳐 주세요" | "다시 해 주세요" |

마케팅방주에서 주문했다면 **마이페이지 → 컨펌 요청**에서 결과물마다 '승인' 또는 '수정 요청'을 남길 수 있어요. 상태는 컨펌 대기·승인 완료·수정 요청으로 표시돼요. 주문 전에 준비할 자료는 [마케팅 대행 맡길 때 준비할 자료](/column/marketing-order-checklist/)를 참고하세요.

## 정기적으로 확인하고 싶다면

AI 답변에서 가게가 어떻게 소개되는지 정기적으로 보고 싶다면 마케팅방주의 **AI 인용 모니터링 리포트**(월 1회 30,000원, 부가세 별도)로 주요 질문별 인용 현황과 변화를 받아 볼 수 있어요. 다른 운영 가이드는 [마케팅 칼럼](/column/)에 모아 두었어요.
