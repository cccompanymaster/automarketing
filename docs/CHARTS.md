# 차트·표 가이드

사이트의 차트는 `src/components/charts/`의 공용 부품만 써요. 규칙은 데이터 시각화 스킬(dataviz) 기준이에요.

## 색
- 계열 색은 3개까지: 브랜드 초록 `#047857` → 파랑 `#2a78d6` → 주황 `#eb6834` (이 순서 고정).
- 흰 카드 배경 기준으로 검증 스크립트를 통과한 조합이에요(색약 시뮬레이션 포함). 4번째 계열이 필요하면 '기타'로 묶어요.
- 강조형: 이야기하는 막대만 초록, 나머지는 회색 `#94a3b8`.
- 글자는 계열 색을 입히지 않아요. 색은 막대·점·범례 표시에만 써요.

## 부품
| 부품 | 언제 |
|---|---|
| `ColumnChart` + `ChartFrame` | 날짜별 추이(1~3계열). 막대에 마우스·키보드를 올리면 그날 모든 값이 나오는 툴팁 |
| `PartsChart` (`SegmentedBar` tall) | 하나의 합계를 2~3부분으로 나눌 때 (총 고용비용, 총 상환액, 판매가 구성) |
| `SegmentedBar` thin | 표 안에서 행마다 비율만 보여 줄 때 (숫자는 옆 칸에) |
| `RankedBars` | 항목을 크기순으로 비교할 때 (고정비 항목별 비중) |

모든 차트에는 **'표로 보기'** 버튼이 있어서 툴팁 없이도 모든 값을 읽을 수 있어요.

## 마크 규칙
막대 굵기 12px 이하(목록형 10px), 끝만 4px 둥글게·기준선 쪽은 각지게, 맞닿는 막대는 2px 간격, 눈금선은 실선 1px.

## 블로그·칼럼 표
마크다운 표에서 금액·비율·수량만 있는 칸은 자동으로 오른쪽 정렬·같은 폭 숫자로 바뀌어요(`markNumberCells`, `src/lib/blog.ts`).
