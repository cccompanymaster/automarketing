## 중간정산이 가능한 사유

근로자퇴직급여 보장법 시행령 제3조 기준이에요 (2026-11-10 확인). 아래 사유가 있을 때 **직원이 요구하면** 퇴직금을 미리 정산할 수 있어요.

| 사유 | 요건 |
|---|---|
| 주택 구입 | 무주택자인 직원이 본인 명의로 주택을 살 때 |
| 전세금·보증금 | 무주택자인 직원이 주거 목적 전세금·보증금을 낼 때 (한 사업장에서 1회) |
| 요양 의료비 | 본인·배우자·부양가족이 6개월 이상 요양하고, 의료비가 연간 임금총액의 12.5%를 넘을 때 |
| 파산 | 최근 5년 안에 파산선고를 받았을 때 |
| 개인회생 | 최근 5년 안에 개인회생절차 개시결정을 받았을 때 |
| 임금피크제 | 임금피크제로 임금이 줄어들 때 |
| 근로시간 단축 | 소정근로시간을 1일 1시간 또는 1주 5시간 이상 줄여 3개월 이상 일하기로 했을 때 |
| 근로시간 단축 제도 시행 | 법정 근로시간 단축으로 임금이 줄어들 때 |
| 재난 | 고용노동부 장관이 정한 재난으로 피해를 입었을 때 |

## 사장님이 챙길 서류

중간정산을 했다면 **근로관계가 끝난 날부터 5년 동안** 사유를 증명하는 서류를 보관해야 해요.

| 사유 | 보관할 서류 (예) |
|---|---|
| 주택 구입 | 매매계약서, 무주택 확인 서류 |
| 전세금 | 전세(임대차)계약서, 무주택 확인 서류 |
| 요양 의료비 | 진단서, 의료비 영수증 |
| 파산·회생 | 법원 결정문 |
| 근로시간 단축 | 근로시간 변경 합의서 |

## 정산 후 퇴직금 계산

중간정산을 하면 근속기간이 새로 시작돼요. 퇴직할 때는 **중간정산한 다음 날부터 퇴직일까지** 기간으로 퇴직금을 계산해요. 계산 방법은 [퇴직금 계산법](/blog/severance-pay-calculation/)을 보세요.

## 주의할 점

- 사유 없이 매달 월급에 퇴직금을 나눠 주는 방식(퇴직금 분할 지급)은 퇴직금으로 인정되지 않을 수 있어요.
- 중간정산 신청서와 증빙을 받고, 지급 내역을 임금대장과 함께 보관하세요. 보존 기준은 [근로자 명부·근로계약서 3년 보존](/blog/employee-records-retention/)에도 정리했어요.
