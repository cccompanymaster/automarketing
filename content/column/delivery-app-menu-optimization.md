## 메뉴판 구성

2026-11-23 기준으로 정리했어요.

| 위치 | 넣을 것 |
|---|---|
| 맨 위 | 대표 메뉴 3개 (사진 필수) |
| 그다음 | 1인 세트·2인 세트처럼 인원별 구성 |
| 중간 | 단품 메뉴 (분류 5개 이하) |
| 아래 | 사이드·음료·추가 옵션 |

## 사진 찍는 법

- **실제 양이 보이게**: 배달 용기에 담은 그대로 찍어요. 손님이 받는 모습과 같아야 해요.
- **자연광 + 위에서 45도**: 그릇 안쪽이 잘 보여요.
- **한 장에 한 메뉴**: 여러 메뉴를 한 사진에 넣으면 무엇을 시키는지 헷갈려요.
- 직접 찍은 사진만 쓰기 ([블로그 사진 찍는 법](/column/blog-photo-guide/)).

## 메뉴 설명 한 줄 공식

**구성 + 양 + 맛 특징 + 추천 대상**

| 아쉬운 설명 | 좋은 설명 |
|---|---|
| "인기 메뉴!" | "닭다리살 300g + 밥 + 샐러드, 중간 매운맛, 혼밥 추천" |
| "맛있는 세트" | "떡볶이 2인분 + 튀김 5개 + 음료 2, 2~3인용" |

## 가게 소개·공지

- 영업시간, 휴무일, 조리 시간
- 포장 방식(국물 따로, 소스 따로 등)
- 알레르기 재료 안내
- 재료 원칙 한 줄 ("매일 아침 직접 손질")

## 가격은 수수료까지 계산해서

배달앱 수수료·배달비를 빼고도 남는지 확인한 뒤 가격을 정하세요. [배달 가격 계산기](/tools/delivery-price/)로 계산할 수 있고, 매장 메뉴판과 가격을 다르게 받는다면 소개에 안내해 두세요 ([메뉴판·가격표 잘 만드는 법](/column/menu-price-board-guide/)).

## 리뷰 이벤트 주의점

- 리뷰 작성 여부와 관계없이 같은 혜택을 주거나, 조건을 분명히 알려요.
- **좋은 리뷰만** 쓰도록 요구하지 않아요.
- 쿠폰·리뷰 이벤트 비용은 [할인 이벤트 기획하는 법](/column/store-promotion-planning/)의 계산법으로 먼저 따져 보세요.

조리 과정 영상은 [가게 숏폼 영상 찍는 법](/column/shortform-video-guide/)을 참고해 메뉴 소개에 활용할 수 있어요. 다른 운영 가이드는 [마케팅 칼럼](/column/)에 모아 두었어요.
