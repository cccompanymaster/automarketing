## 이전 일정표

2026-11-25 기준으로 정리했어요.

| 시기 | 할 일 |
|---|---|
| D-30 | 이전 날짜 확정, 매장·SNS·플레이스 소식으로 1차 공지 |
| D-14 | 새 매장 사진 촬영, 블로그 글 준비, 단골 연락(수신동의한 손님만) |
| D-7 | 2차 공지, 기존 매장 안내문 제작 |
| D-day | **모든 채널 주소·전화·영업시간을 같은 날 변경** |
| D+1~14 | 새 위치 블로그 글, 이전 오픈 이벤트, 리뷰 답글 |

## 같은 날 바꿀 곳

| 채널 | 확인 |
|---|---|
| 네이버 플레이스 | 주소·지도 핀·찾아오는 길·사진 |
| 카카오맵 | 주소·전화 |
| Google 비즈니스 프로필 | 주소·인증 ([구글 비즈니스 프로필 등록하는 법](/column/google-business-profile/)) |
| 인스타그램·카카오톡 채널 | 프로필 주소·하이라이트 |
| 배달앱 | 주소·배달 가능 지역 |
| 홈페이지·명함·영수증 | 주소·전화 |
| 사업자등록 | 사업장 이전 정정신고 ([사업자등록 정정](/blog/business-registration-correction/)) |

플랫폼마다 주소 변경과 리뷰 처리 기준이 다르니, 이전 전에 각 고객센터에 확인하세요.

## 기존 매장 안내문

- 새 주소와 **약도 QR**
- 새 매장 오픈 날짜와 영업시간
- 연락처, 카카오톡 채널 QR
- 현수막은 지자체 신고·게시 기준 확인 ([전단지·현수막 홍보 규칙](/column/flyer-banner-rules/))

## 새 위치 알리기

1. **블로그 글**: "○○동으로 이전했어요"처럼 옛 동네 이름과 새 동네 이름을 함께 써서 두 지역에서 모두 찾을 수 있게 해요. 직접 쓰기 어렵다면 마케팅방주의 **블로그 최적 배포**(1건 19,900원, 부가세 별도)로 알릴 수 있어요. 대가성 글에는 광고 표시가 들어가요.
2. **이전 오픈 이벤트**: 기존 단골 확인(영수증·멤버십) 시 혜택. 할인 폭은 [할인 이벤트 기획하는 법](/column/store-promotion-planning/)으로 먼저 계산하세요.
3. **오픈 준비 체크**: [가게 오픈 전 마케팅 준비](/column/store-opening-marketing-checklist/)의 D-30 체크리스트를 그대로 활용하세요.

다른 운영 가이드는 [마케팅 칼럼](/column/)에 모아 두었어요.
