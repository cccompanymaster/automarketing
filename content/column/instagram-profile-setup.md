## 첫 화면 5가지

손님은 프로필에 들어와 몇 초 안에 머물지 정해요. 아래 다섯 칸만 채워도 문의가 늘어요 (2026-11-10 기준 정리).

| 칸 | 이렇게 채우세요 | 예시 |
|---|---|---|
| 1. 이름 | 가게명 + 지역·업종 (검색에 걸려요) | ○○식당 · 송도 삼겹살 |
| 2. 소개 (150자) | 대표 메뉴, 위치, 영업시간, 예약 방법 | 아래 예시 참고 |
| 3. 링크 | 예약·주문이 일어나는 곳 | 네이버 예약, 카카오톡 채널 |
| 4. 하이라이트 | 메뉴 · 위치 · 후기 · 이벤트 | 동그란 표지 4~5개 |
| 5. 고정 게시물 | 대표 메뉴, 찾아오는 길, 진행 중 이벤트 | 맨 위 3개 고정 |

## 소개 문구 예시 (150자 안)

```
🥩 48시간 숙성 삼겹살 · 가족 단체룸
📍 송도 센트럴파크역 3번 출구 도보 5분
⏰ 11:00~21:00 (월 휴무) · 주차 2시간 무료
👇 예약은 아래 링크에서
```

한 줄에 한 가지 정보만 쓰면 휴대폰에서 읽기 쉬워요.

## 프로페셔널 계정으로 바꾸세요

설정에서 **프로페셔널 계정(비즈니스)**으로 전환하면 아래 기능이 생겨요.

- 연락처·길찾기 버튼
- 게시물별 도달·저장·공유 통계(인사이트)
- 업종 카테고리 표시

## 게시물은 '저장할 만한 정보'로

- 메뉴판·가격표 사진
- 주차·찾아오는 길 안내
- 계절 메뉴·이벤트 소식

손님이 저장하고 친구에게 공유할 만한 정보가 쌓이면 프로필이 자연스럽게 커져요. 팔로워를 돈으로 사는 방식은 반응률을 떨어뜨려 권하지 않아요.
