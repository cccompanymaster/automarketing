## 꼭 지킬 5가지

정보통신망법과 시행령 기준이에요 (2026-11-13 확인).

| 규칙 | 내용 |
|---|---|
| 사전 수신동의 | 광고 문자를 받겠다는 동의를 **미리** 받기 |
| (광고) 표시 | 문자 **첫머리**에 `(광고)` |
| 보낸 곳 표시 | 가게 이름과 연락처 |
| 무료 수신거부 | 문자 끝에 무료로 거부하는 방법 (예: 무료거부 080 번호) |
| 야간 발송 제한 | **오후 9시 ~ 다음 날 오전 8시**에는 별도 동의 없이 보내지 않기 |

## 수신동의는 이렇게 받아요

- 결제할 때 종이·태블릿 동의서, 예약 폼 체크박스처럼 **손님이 직접 체크**하게 하세요. 미리 체크해 둔 칸은 동의로 보기 어려워요.
- 무엇을, 어떤 채널(문자·카카오톡)로 보내는지 알려 주세요.
- 동의를 받은 날부터 **2년마다** 계속 받을지 손님에게 확인해야 해요.
- 동의 기록(날짜·방법)을 남겨 두세요.

예외로, 거래하면서 연락처를 직접 받은 손님에게는 거래가 끝난 날부터 **6개월 안에** 같은 종류의 상품 광고를 동의 없이 보낼 수 있어요.

## 바로 쓰는 문자 예시

```
(광고) 연수동 ○○카페
11월 한정, 아메리카노 2잔 주문 시 쿠키 1개 증정!
기간: 11/15~11/30
문의 032-000-0000
무료거부 080-000-0000
```

문자 안 링크에 [UTM](/column/utm-link-guide/)을 붙여 두면 문자를 보고 들어온 손님 수를 따로 확인할 수 있어요.

## 어기면

수신동의 없이 보내거나 (광고) 표시·수신거부 방법을 빠뜨리면 **3천만 원 이하의 과태료**를 받을 수 있어요. 손님 한 명의 스팸 신고로도 조사가 시작될 수 있어요.

## 문자보다 먼저 해 볼 것

광고 문자는 동의한 손님에게만 갈 수 있어서 새 손님을 모으기엔 한계가 있어요. 새 손님은 블로그·플레이스·당근 같은 채널로 모으고, 문자는 이미 온 손님을 다시 부르는 데 쓰는 편이 효율적이에요. 채널별 예산 나누는 법은 [소상공인 마케팅 예산](/column/marketing-budget-plan/)을, 대가성 후기 표시 규칙은 [협찬·광고 표시 하는 법](/column/sponsored-post-disclosure/)을, 다른 운영 가이드는 [마케팅 칼럼](/column/)을 참고하세요.
